# 产业、宏观与事件研究

第一轮从两个熟悉的产业链深入，不把所有商品新闻堆成知识体系。下列是研究问题，不是交易建议。

| 方向 | 要建立的机制图 | 易混淆之处 |
|---|---|---|
| 黑色 | 原料—冶炼—钢材—下游、利润与库存 | 钢厂库存、社会库存、仓单不同；名义相关并非风险分散 |
| 有色/贵金属 | 矿端—冶炼—加工、库存、进口及资金条件 | 美元、汇率、品级、交割与地区基差不可直接混用 |
| 能源化工 | 原油/煤—中间品—化工、装置、裂解与加工利润 | 产能不是产量；不同油种和交割地不是同一现货 |
| 油脂油料 | 种植—天气—出口—压榨—油粕—需求 | USDA 初值/修订、产地季节、进口时滞、加工比例 |
| 农产品 | 作物周期、产区/天气、贸易、库存与替代 | 自然季节与交割月份选择偏差需要分离 |
| 新能源材料 | 供给扩张、成本曲线、库存与下游需求 | 新品种样本短、制度与产业结构变化可能很大 |

## 每条链的六份记录

供需流程图；品种与可交割品说明；变量字典（单位/地区/频率）；来源与发布时间表；解释相反方向的机制；一个可检验假设。资料不足时指出缺口，不编造数据。

## 宏观与海外联动

将政策、增长、通胀、利率、美元、汇率、海外供需事件转换成带时间戳的研究变量。预测是条件性的，不能使用“降息必涨”“库存下降必涨”这样的固定结论。

基础来源：[国家统计局](https://www.stats.gov.cn/)、[ALFRED](https://alfred.stlouisfed.org/)、[EIA](https://www.eia.gov/petroleum/supply/weekly/)、[USDA WASDE 档案](https://esmis.nal.usda.gov/publication/world-agricultural-supply-and-demand-estimates)。这些来源分别提供统计/历史版本/能源/农业信息；不代表覆盖全部国内可交易变量。

事件实验记录初次公布时刻、市场此前预期是否真的可得、交易时段、反应窗口及修订。无法获得历史预期时，只能研究公布值或公告前后反应，不能把它写成“预期差策略”。
