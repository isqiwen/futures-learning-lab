# 数据、许可与安全

真实行情、付费研究、账户数据和密钥均保存在仓库外。`.gitignore` 是防误操作，不是秘密保护系统；提交前仍需人工检查。默认发布私有仓库，不自动改变可见性。

`data/manifests/` 仅保存允许分享的来源、schema、覆盖、版本及哈希；原始数据、API token、真实账户号、成交明细及持仓不进入 Git。公开可浏览不等于可再分发，数据使用条款需逐源核验。

课程、论文只保存合法链接、引文和个人原创笔记；不打包教材 PDF、付费报告或未经许可的课程答案。第三方代码的复用需保留对应许可和出处。

规则记录至少有：交易所、具体合约、适用日期、查询日期、原始出处、手续费口径、保证金口径和期货公司差异。当前包不内置现行费率、保证金比例、账户门槛或自动化交易合规结论。

教学示例 `DEMO` 是虚构合约；其乘数、价格、费用和保证金率不能用于任何真实交易。

本学习包没有完整验证当前程序化交易报告要求、期货公司接入条款或所有自然人交割约束；这些是 M1/M7 中须逐项核验的任务，未核验不得宣称满足实盘条件。
