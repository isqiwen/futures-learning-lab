# 十八项复现候选：问题、对照与验收

迁入后保留 R01–R18 身份，关联 [50 篇论文](papers_manifest.csv) 和 [实验登记表](replications.csv)。这些是**待实施的研究规格**，不是已经实现的实验，也不是 52 周中额外的十八个必做工作包。各项的参数、公式与样本需在取得并核对全文后锁定。

先使用 R01 完成术语/数据前置检查，再做 `R04 TSMOM → R02 CSMOM → R09 Carry`。没有原文原始数据时，把结果称为国内迁移或方法复现，不声称复制原论文数值。

## 实验目录与具体问题

| ID / 论文编号 | 问题与最小实现 | 必须有的对照或核对 |
|---|---|---|
| R01 / #7 Fama–French | 定义现货基差、近远月曲线和 carry；保留真实到期日与品种 | 单位、符号、剩余期限与现金流手算；没有现货数据就不声称重现现货基差检验 |
| R02 / #13 Miffre–Rallis | 同一决策快照内按品种排序，形成 winner-minus-loser 组合 | 排序可得时间、缺失品种、等权/波动率权重、板块集中度；不是把每个月份当独立股票 |
| R03 / #14 Fuertes 等 | 比较动量、期限结构与组合/双排序 | 单因子、组合的共同样本与相同成本；不把所有试出的排序规则只报告最佳者 |
| R04 / #16 Moskowitz 等 | 按品种自身滞后收益生成趋势目标，组合真实合约 | 信号和事前波动率估计独立记录；相同规则跨品种；连续序列不能直接下单 |
| R05 / #15 Hong–Yogo | 研究 OI 增长是否在价格信息以外有增量 | 区分合约 OI 与品种汇总、换月效应；price×OI 等属于单独登记扩展，不自动视为论文定义 |
| R06 / #17 Gorton 等 | 库存状态、基差与后续收益的关系 | 发布时间、修订与季节性；仓单不自动等同总库存；缺少 PIT 数据则明确限制 |
| R07 / #21 Szymanowska 等 | 按原文定义分解 spot/term premium 并构造基准 | 组件与总收益的口径一致；价格变化、换月差与真实现金盈亏不能随意混加 |
| R08 / #23 Kim 等 | 分离 TSMOM 信号与波动率缩放效果 | 四组：未缩放方向基准、缩放基准、未缩放 TSMOM、缩放 TSMOM；统一杠杆与费用口径 |
| R09 / #27 Koijen 等 | 期限可比的 carry，比较不同月份选择规则 | 分母/年化/符号；近月、远月流动性；carry 预测值不等于已实现 roll profit |
| R10 / #29 Boons–Porras Prado | 严格实现 basis-momentum，而非任意基差变化率 | 与价格动量及 level carry 比较；全文公式、各腿收益和持有期间单独核对 |
| R11 / #30 Bakshi 等 | 构造 average、carry、momentum 基准用于归因 | 候选策略共同样本、因子相关性、回归假设与区间；alpha 不等于套利保证 |
| R12 / #31 Ham 等 | 中国合约上的时间序列动量迁移 | 夜盘交易日、费用、换月、不能成交情形；与 R04 共用定义而不复制第二套策略 |
| R13 / #32 Zhang 等 | 中国品种截面的 carry/momentum/average 因子 | 动态可交易池、存续与数据覆盖偏差、期间外结果；区分原文复现与现代扩展 |
| R14 / #40 Wang–Zhang | 商品特征与宏观变量的表格 ML 基准 | 线性/正则化与一个树模型，滚动训练；同信息集、fit 边界、预测与净收益分别评价 |
| R15 / #41 Angelidis 等 | 在同等信息和搜索预算下比较 TS 与 CS 预测 | 不默认 pooled 模型胜出；预测误差、截面 rank、成本和各板块稳定性同时报告 |
| R16 / #35 Cheng 等 | LLM 生成可确定计算的因子假设 | 固定 prompt/模型/输出；记录全部候选与去重；隔离执行；测试集禁止反馈到生成循环 |
| R17 / #36 Zheng 等 | 同品种曲线不同期限的相对动量 | 月份级数据和流动性；多腿风险、不同成交时刻、费用/保证金；不能仅凭两条价格之差算无风险利润 |
| R18 / #37 Han 等 | 研报文本到品种特征及后续收益 | 发布时间/首次获得、原文哈希；简单词典或可用文本模型对照；LLM 版本是扩展，不混作原论文方法 |

## 数据契约

在现有 `research/` 写预注册规格，在 `labs/<实验标识>/` 放小型代码与测试。至少固定：

- 来源权限、下载/提取方式、快照身份、样本覆盖和缺失政策；不能提交受限原始市场数据。
- `contract`、`variety`、`curve` 的研究单位，合约规格及条款有效日期；近月/主力/远月的选择信息只来自决策时点。
- 行情时刻、bar 完成、发布/首次可得、决策与最早执行时间；夜盘自然日与交易日分开。
- 特征、标签窗口、训练/验证/测试、所有拟合预处理、缺失/标准化规则及回放限制。
- 风险缩放、资金分母、目标到整手、换月/滑点/费率/涨跌停及流动性约束。

后验修订的数据集必须标注其证据限制，不能仅为每行添加时间戳就称为历史 PIT。日线不能支撑未经声明的分钟级执行结论；用分钟数据做标签仍需处理重叠与相关性。

## 统一交付物

使用 [实验模板](../templates/experiment.md) 与 [论文评审模板](../templates/paper-review.md)。实际开展后再创建：

```text
research/<实验标识>/spec.md       # 原文版本、假设、偏离项、失败条件
labs/<实验标识>/                 # 真正实现的小型程序与测试
reports/<实验标识>.md            # 已实际运行的结果、局限、复跑命令
```

完整原始输出和大体积数据留在有权限的本地存储；报告记录其哈希、访问条件和汇总结果。参数预算、全部尝试与留出集使用情况进入既有 trial register，不仅保存获胜版本。

## 必须区分的三种证据

1. **方法/实现核对**：合成数据、手算或有限输入，说明代码是否符合定义。
2. **论文复现或国内迁移**：说明原文样本/版本是否可得、哪些内容替换以及所得证据。
3. **未来实施可行性**：手续费、流动性、限价约束、模拟偏差与生产验证，不能由前两者直接推导。

不是所有指标适用于所有实验。预测任务报告损失/IC/RankIC，组合任务报告毛/净收益、风险、回撤、换手、集中度和成本敏感性；都要有最简单有效基线、反例与不确定性。高 Sharpe 不是完成条件，负结果也不降低研究诚信。

## 登记规则

`replications.csv` 中阶段与依赖是建议的知识关系；实际先满足现有阶段门槛。`not_started → in_progress → review → completed`，阻塞可记录 `blocked`。`review/completed` 需要仓库内报告路径；`completed` 还必须本人确认，CI 不能自动授予掌握。

元数据未核验的论文，在实施前先核验标题、作者、年份、DOI和所用全文版本。原文尚不可得或数据不合适时保留 `blocked` 和原因，不悄悄更换研究问题。现有 PROGRESS 和学习 Issue 继续拥有能力验收，不由本表替代。
