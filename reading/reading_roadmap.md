# 阅读路线：书籍 + 论文 + 代码

本路线迁自 `qlib-futures`，并纳入本仓库已有的 [八阶段路线](../ROADMAP.md) 与 [52 周执行基线](../docs/weekly-plan.md)。它回答“本阶段读什么、用什么实验检验”，不是另一套排期或已完成记录。

**教材搭体系，论文界定假设，实验检验结论。** 不必等找到全部付费论文，或者读完五本书，才开始合约、结算和时间语义的小实验。

## 快速入口

当前优先事项仍是 [QF-W01 能力诊断与时间预算](../START_HERE.md)。已有代码不等于本人掌握；诊断后可按能力调节阅读量，不能跳过数据与资金正确性检查。

第一轮搭配：Hull 第九版 `1 概览 → 2 → 3 → 4 基础 → 5 → 34 选读`，再用 Carver 的信号与定仓主题配合趋势实验。详见 [五本书的版本、选章和练习](books.md)。

```text
合约卡 / 逐日结算 / 可得时间
    → R01 的基础定义与曲线数据检查
    → R04 TSMOM
    → R02 CSMOM
    → R09 Carry
    → 按证据和数据条件扩展
```

R 编号保持迁移前身份，不是执行顺序。第一次可直接使用国内真实合约数据，但必须标为“中国市场迁移检验”；不能因使用了相同公式就宣称重现原论文样本。

## 经典理论怎样配论文

库存、仓储、便利收益对应 Working（#2）与 Fama–French（#7）；套保需求、风险承担对应 Hirshleifer（#8）与 Bessembinder（#9）。先能独立解释现货/期货、近远月、风险溢价，再深入推导。原文暂不可得时，登记来源阻塞，可先用已获得的教材完成基础练习，不伪造论文精读笔记。

R01–R11 保留经典因子研究线：basis、CSMOM、动量与期限结构组合、TSMOM、OI、库存、风险溢价分解、波动率缩放、carry、basis-momentum、三因子基准。每项须核实论文版本与精确公式，参数变体单独登记。

## ML 与 AI 的进入条件

先使真实合约映射、标签和滚动评价可靠，再在相同信息集与成本假设下比较：历史均值/适用的 AR 基准、线性模型、Ridge/Lasso/ElasticNet、一个树模型；神经网络是后续候选，而非升级目标。

R14/R15 比较 pooled cross-sectional 与单品种/time-series 方法，不能预先宣布任何一方必胜。报告预测损失、OOS R²、IC/RankIC、净收益、换手、回撤、板块与时期稳定性；全样本拟合标准化/特征筛选不允许。表现没有超过简单基准也可以形成合格研究结果。

文本方向优先新闻/研报/公告到可审计特征，以及 LLM 产生待验证因子假设。R16/R18 和 #49 提供研究线索；FinBERT、BloombergGPT、FinGPT 是支持方法，不是国内期货收益保证。保存原文来源与哈希、首次可得时刻、模型/提示词版本和原始输出。模型训练截止日声明本身不足以证明不存在历史污染；冻结生成过程、留出未使用测试集并讨论限制。

TFT/MASTER 等时间序列或跨资产模型先与正则化线性/树模型对比；不要只用价格 RMSE 代替含成本经济评价。RL 留到成交与成本环境可信之后，先选执行或仓位转换中的一个问题，不让一个策略同时承担发现 alpha、资金分配、订单执行和安全授权。

## 三遍阅读法

第一遍看摘要、引言、结论、图表和样本说明，回答研究问题、经济机制、市场/时期、研究维度与可证伪条件。

第二遍看数据构造、信号/标签、形成与持有期、组合、风险缩放、成本和稳健性，将其写为规格。

第三遍在实现时核对真实合约、可得时间、复权/换月、缺失数据、排序/归一化、重平衡和成交时刻；逐条记录与原文差异。来源暂未核验则先做核验，不把旧清单的一行描述当作公式。

## 实验和验收

从 [复现规格](replication_plan.md) 选一项，使用 [论文评审](../templates/paper-review.md) 和 [实验记录](../templates/experiment.md)。先定义失败条件、参数预算、数据权限与快照，再运行。研究原文规格、国内迁移和个人扩展分开报告，测试集不得反复选参。

最少核对：特征无未来信息；真实合约收益与连续序列跳空分离；风险缩放使用事前信息；手续费/换月/滑点口径明确；拒绝交易与缺失样本有记录；既有试验包括负结果完整保留。

## 时间预算与周循环

40% 教材 / 40% 论文 / 20% 代码可作入门期参考，之后向 20% / 40% / 40% 调整；这不是实证最优比例或固定日程。总工时以本人确认的预算为准，一周只推进一个核心实践与一个配套阅读。

每周留下术语推导、书/论文规格、可复跑的小实验、失败分析或具体数据需求之一，再独立复述。用已有 [周复盘模板](../templates/weekly-review.md)；只有本人验收后才更新能力进度。
